Craftee Website Concept

User Experience Design

For my UXD module in first year, I created a website for a fictional knit and crochet website called Craftee. I created a logo and branding for them to use throughout the website.

Excel Plane Model

Maths for Graphics and Statistics

I used VBA code in Excel to create interactive 2D and 3D models of a plane using matrix algebra and cubic splines to transform and animate the model as well as generate solid and wireframe views.

This taught me a lot about my ability to apply concepts learned in one programming language (such as JavaScript) to quickly develop proficiency in another language I have no prior experience with such as VBA.

2D Model

I represented a simple 2D model of a plane on a scatter graph in Excel. I then set up matrix calculations to transform and move the plane.

Next, I used VBA code to animate the movement of the plane using conditional statements and loops. I created a simple user interface and linked the buttons to the VBA code.

The plane can fly in a straight line, fly and return to the starting point, or fly along the path of a cubic spline. There are also other controls to rotate and move the plane.

3D Model

I determined the coordinates of each point of a simple 3D plane model and which faces they belonged to. I then respresented this model on a scatter graph in Excel. Again, I set up matrix calculations to transform and move the plane, this time in 3D.

I also calculated the average depth, illumination factor, and visibility of each face with respect to parallel projection to help me to render wireframe and solid views of the plane. The average depth was ranked from furthest to closest to solve the Painter's Algorithm and render the solid plane with lighting effects.

I made another simple UI with controls that made more sense for a 3D model, and wrote VBA to transform the plane.

The plane can be rotated in all three directions, scaled, and the perspective and view can be changed. There is a gallery of poses and a small animation as well.

Newspaper Database

Database Fundamentals

I compiled a design document and built a relational database for a newspaper company in MySQL with a catalogue of sample queries for my Database Fundamentals class.

Building the database from scratch taught me a huge amount about relational databases and how they are applied to real world scenarios.

Design Document

I started off with a description of the system, identifying the entities, relationships, and cardinality. I translated this into an ER diagram.

I then used the ER diagram as the basis for my logical data model. I identified participation constraints, multivalued attributes, and resolved many-to-many relationships.

SQL Implementation

I created tables in the database and populated them with data.

In a seperate SQL script, I created a list of sample queries.
